# KuGou Lite for Spotube

**KuGou Lite** 是一个面向 [Spotube](https://github.com/team-spotube/spotube)
的酷狗概念版音乐插件。安装后，可以在 Spotube
中使用酷狗账号提供的歌曲搜索、个人歌单、歌曲信息、播放音源和歌词服务。

插件通过酷狗／酷狗概念版账号授权获取相应内容，并将歌曲元数据、音源和歌词接入
Spotube。你可以继续使用 Spotube
的播放界面、播放队列和媒体控制功能，不需要在两个音乐应用之间来回切换。

> 当前公开发行版本：**v0.1.1**\
> 适配目标：**Spotube 6.x**\
> 插件 API：**0.1.0**

## 功能介绍

### 1. 酷狗账号登录

-   支持通过二维码登录酷狗或酷狗概念版账号。
-   登录授权成功后保存会话信息，后续使用时无需每次重新扫码。
-   支持查询当前账号的会员状态。
-   按账号区分缓存数据，避免不同账号之间的缓存内容混用。

### 2. 歌曲搜索与个人歌单

-   使用酷狗音乐服务搜索歌曲。
-   浏览账号下的个人歌单。
-   查看收藏歌曲及其收藏状态。
-   在插件首页展示已获取的个人歌单，便于继续浏览和播放。
-   支持读取已加载过的歌单列表和曲目分页缓存。

### 3. 歌曲信息与封面

插件为 Spotube 提供歌曲播放所需的基础信息，包括：

-   歌曲名称
-   歌手信息
-   专辑封面
-   歌曲时长

同时会清理部分歌曲名称末尾多余的 `.mp3` 后缀，避免文件后缀出现在 Spotube
的歌曲标题中。

### 4. 酷狗音源与播放

-   根据当前登录账号的授权情况请求歌曲音源。
-   Spotube
    请求播放地址时，插件会重新解析音源，而不是依赖长期保存的过期播放地址。
-   获取到的音源由 Spotube
    播放，播放队列、后台播放、系统媒体卡片和通知等功能仍由 Spotube
    管理。

**音源可用性说明：**
不同歌曲的可播放情况可能不同，实际结果取决于酷狗服务响应、歌曲版权状态以及当前账号拥有的授权和权益。插件不承诺所有歌曲均可获取音源，也不提供会员权限或版权限制的绕过功能。

### 5. LRC 歌词

-   获取歌曲对应的 LRC 歌词。
-   将歌词内容提供给 Spotube 的歌词显示功能。
-   歌词是否存在以及是否能够获取，取决于酷狗服务端的数据情况。

### 6. 已访问内容缓存

-   缓存已加载的个人歌单列表和曲目分页。
-   缓存按账号隔离。
-   断网时可以读取此前已经加载并缓存的歌单及曲目数据。

离线浏览有明确范围：**需要先联网打开过相应歌单或曲目页面**。未曾加载的内容无法凭空离线获取。插件缓存的是歌单、曲目等信息，不代表已经下载了歌曲音频文件；音频播放和相关下载行为由
Spotube 管理。

## 安装与使用

### 安装插件

1.  从本仓库的 `dist` 目录下载发行包：\
    [`spotube-plugin-kugou-lite-0.1.1.smplug`](dist/spotube-plugin-kugou-lite-0.1.1.smplug)
2.  将文件保存到设备。
3.  打开 Spotube，进入设置中的插件管理页面。
4.  选择本地导入插件，并导入下载的 `.smplug` 文件。
5.  确认插件版本为 `0.1.1`。

### 登录酷狗账号

1.  在 Spotube 的插件管理页面找到 **KuGou Lite**。
2.  进入插件登录功能，获取授权二维码。
3.  使用酷狗或酷狗概念版 App 扫描二维码。
4.  在手机端确认授权。
5.  返回 Spotube，等待账号信息加载完成。

请使用你本人有权使用的账号完成授权。不要将账号密码、登录二维码或会话信息分享给他人。

### 设置音乐来源

安装并登录后，在 Spotube 的来源设置中按需选择 **KuGou Lite**：

-   **元数据来源（Metadata）：** 提供歌曲名称、歌手、封面、时长等信息。
-   **音源来源（Audio）：** 提供歌曲播放地址。
-   **歌词来源（Lyrics）：** 提供 LRC 歌词。

如果只选择其中一项，其他内容仍可能由 Spotube
当前配置的其他来源提供。建议根据自己的使用需求分别设置。

### 搜索和播放歌曲

1.  在 Spotube 中搜索歌曲。
2.  选择搜索结果并加入播放队列。
3.  Spotube 会通过已配置的 KuGou Lite 来源获取歌曲信息、播放音源和歌词。
4.  正常播放时，后台播放、媒体通知和系统媒体控制由 Spotube 负责。

如果切换插件版本后，播放队列仍显示旧的歌曲标题，可以重新从歌单或搜索结果中选择歌曲，以刷新队列中的歌曲信息。

## 当前功能范围与已知限制

当前版本主要覆盖账号授权、歌曲搜索、个人歌单浏览、歌曲信息、音源获取和
LRC 歌词。以下功能尚未实现：

-   创建、编辑或删除歌单。
-   添加或移除歌曲收藏等写入操作。
-   独立的歌手详情页面。
-   独立的专辑详情页面。
-   KRC 歌词及其翻译内容。

此外：

-   离线浏览仅适用于此前已经联网加载并缓存的歌单和曲目数据。
-   插件缓存不包含歌曲音频文件。
-   部分歌曲可能因版权、地区、账号权益或服务端响应而无法播放。
-   插件依赖酷狗相关服务接口，接口行为或服务策略变化可能影响部分功能。
